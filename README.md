# Daniel Trujillo — Portfolio

A responsive, dependency-free portfolio website. Open index.html in your browser to preview it.

## Customize

Edit index.html to update your introduction, project descriptions, and GitHub links. The camera-tracking image is an illustration, not a project screenshot. Replace it with your own image when available. Add a direct project repository link once you are ready to share it.

## Publish with GitHub Pages

1. Commit and push the website files to main.
2. On GitHub, open the repository's Settings > Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select main and / (root), then Save.
5. GitHub will display the website URL after deployment completes.

Expected URL: https://danieltrujill0.github.io/Website-Portfolio/

## Save changes

```powershell
git add index.html README.md
git commit -m "Build responsive portfolio website"
git push
```
